## 共用流程

普通地图、纯享模式和完整地图 PNG 都调用 `render()`。地形和行走表面先画，实体共用一次世界坐标排序，飞行物随后绘制，天气光照最后叠加。绘制只读取世界，不改变行为或存档。

`scene-depth.js` 提供 `collectSceneItems()`、`scenePart()`、`sortSceneItems()` 和 `drawSceneItems()`。`render.js` 的 `farmSceneItems()` 组合各区域与角色。收集期间，`scenePart()` 仅登记回调；收集结束后才实际画实体。单独调用区域绘制函数时，`scenePart()` 会直接画，方便预览具体美术。

排序键依次是 `layer`、`y`、`order`。同键保持登记顺序。

| 项目 | 接地点和分层方式 |
| --- | --- |
| 地形、道路、桥面、土壤、水纹、低矮地被 | 收集过程中直接画在底层，不用植物顶端排序 |
| 建筑、独立货箱、家具 | 底部落地边缘，每个独立物体分别登记 |
| 树木 | 树干落地点；特殊北岭树使用 `baseY`，不是树冠位置 |
| 普通村民 | `actorDepth(actor)` 为 `actor.y + 22`，与人物脚底一致 |
| 阿运与货车 | `actor.y + 24`；人和推车作为一个移动单元 |
| 牛、鸡、羊、山羊 | 各自绘制函数对应的稳定脚底偏移，不能混用人物偏移 |
| 围栏 | 后排、侧面的每段、前排各自登记；前排与角色接地点相同时时序优先遮挡角色；牛舍和山羊舍接入后侧边界时，栏杆在墙边结束，不穿过门口 |
| 河流桥和西湖栈桥 | 桥面底层，后栏与前栏各自排序，走动人物处于其中 |
| 东岸菜圃 | 土壤底层；上下排植株各自登记，阿葵在中间小路上时位于两排之间 |
| 香草田 | 低矮苗床与植株底层，阿栀采摘时身体显示在植株上方 |
| 休息人物 | 休息点的坐姿接地点，和对应长椅或摇椅相邻排序 |
| 停栖猫头鹰和麻雀 | 借用所在树、井、屋顶、舞台、木柱的深度，在承载物之后绘制，显示在其前方 |
| 欢庆彩带 | 两根支柱的落地深度，绳旗先于同深度木柱绘制；高处绳旗覆盖后方舞台和水井 |
| 飞行鸟和昆虫 | `layer = 1`，不得把地面动物或普通居民放入这一层 |
| 夜灯 | 亮窗和实体灯柱属于原建筑或独立灯柱；天气层只补柔和光晕 |

采集物按各自地面接点登记，采摘人物和觅食动物的脚底位于其前方时会覆盖采集物。水中的鱼点和涟漪留在水面层；西南小湖的低矮岸边背景先画，苍鹭等生物显示在其前方。

## 新增物体的写法

```js
const site = SOME_SHARED_LAYOUT;
scenePart('new-shelter', site.bottom, () => {
  // 只绘制这个物体；不得更新路线、工作进度或资源。
  drawShelter(site);
});
```

同一个函数需要在直接预览与队列中复用时，可在入口登记，实际绘制阶段再次调用原函数：

```js
function drawShelter(site) {
  if (sceneQueue) return scenePart(`shelter:${site.id}`, site.bottom,
    () => drawShelter(site));
  // 实际像素绘制。
}
```

多个分散物体不可共用一个任意深度。先在循环内分别登记，回调使用 `let`/`const` 捕获各自坐标。若需 `ctx.translate()`，必须把 `save()`、`translate()`、实际绘制和 `restore()` 一起放进回调；不能在收集时变换、实际绘制时丢失变换。

接地点只来自世界坐标与稳定尺寸。跳跃、庆典弹跳、弯腰、摇椅摆动和翅膀扇动改变像素位置，不改变排序深度。这样动作不会使人物在建筑前后反复闪烁。

## 回归要求

修改前后关系时，执行 `node kits/farm/tests/smoke.cjs`。遮挡回归包括所有建筑和树木的前后切换、四类居民经过三种前侧围栏、阿葵上下排、西湖栈桥、彩带与水井、麻雀停井、猫头鹰停枝、绘制不修改状态以及全图 PNG。

此外检查实际画面：日常和欢庆日各一次，夜间一次；核对移动角色、暂停动作、高处停栖、道路交叉处和物体轮廓。调整坐标后同步检查命中、路线和小地图。新增物体至少补充其前后切换或附着关系的针对性验证，不能仅确认函数被调用。
