# 苔谷农场 · 性能优化

[v1.3 版本说明](../logs/v1.3.md) · [实现与验证细节](性能优化细节.md) · [代码结构](代码结构.md) · [v1.3 开发历史](history/持续开发记录-v1.2.md)

## 当前结果（2026-10-10）

已完成 **14项优化**，减少地面重复计算、路径构造与固定图案绘制。全部玩法、对象、布局、交互、渲染顺序、存档与动画保持一致。

前13项累计同环境对比，全图CPU绘制均值 **20.59 → 3.55 ms，减少82.8%**。第14项进一步改善移动镜头，拖动、缩放绘制耗时减少约 **13%–14%**；固定全图视角基本不变。

## 做了什么

每行收益相对于当时上一版，不能将百分比相加。前期保留的微小收益已完整验证；后续只继续明显且稳定的收益。

| 项目 | 实现 | 整图绘制耗时收益与限制 |
| --- | --- | --- |
| 1. 基础地面 | 缓存当前视窗草地、渐变与固定纹理，按1:1复制 | 暂停/运行减少约55% |
| 2. 东岸水岸 | 复用水岸几何与颜色分组 | 减少5.2%–6.6% |
| 3. 村口与广场 | 复用固定地面分组 | 减少10.4%–10.6% |
| 4. 道路 | 复用路面与晕边路径，变化时重建 | 减少9.9%–10.8% |
| 5. 湿地 | 按精确湿度和颜色复用分组 | 暂停减少5.4%；运行约1%，P95未改善 |
| 6. 地面路径 | 分组复用原生Path2D，保持像素对齐 | 减少17.6%–23.7% |
| 7. 颜色计算 | 有界缓存相同精确输入的插值结果 | 减少7.6%–9.1%；峰值未改善 |
| 8. 工程分类 | 缓存对象所属工程，显示条件实时判断 | 减少2.3%–3.4%；峰值未改善 |
| 9. 植物占地 | 复用道路/建筑几何判断，其余条件实时检查 | 减少4.4%–4.9% |
| 10. 河湖地面 | 复用静态底色与固定图案分组 | 减少7.8%–9.1% |
| 11. 自然地块筛选 | 原筛选函数共享单帧上下文 | 减少1.1%–1.4% |
| 12. 矿坡地面 | 复用固定岩层与碎石几何 | 减少0.8%–1.7% |
| 13. 水鸭池 | 复用固定底色与高光分组 | 减少1.7%–2.1% |
| 14. 移动镜头颜色 | 复用精确地表颜色，按当前镜头重绘 | 拖动减少13.3%，缩放减少14.0% |

## 累计收益

前13项与最初版本同帧交替绘制，使用相同世界状态、镜头和动画时钟：

| 场景 | 均值：原版 → 优化 | P95：原版 → 优化 | 峰值：原版 → 优化 |
| --- | --- | --- | --- |
| 晴天暂停 | 20.592 → 3.546 ms | 22.60 → 4.00 ms | 36.50 → 8.20 ms |
| 正常运行 | 20.340 → 3.936 ms | 22.20 → 4.30 ms | 32.20 → 7.30 ms |
| 夜晚 | 20.630 → 3.579 ms | 22.00 → 4.20 ms | 37.90 → 7.40 ms |
| 雨天 | 20.412 → 3.417 ms | 21.90 → 3.90 ms | 35.90 → 6.50 ms |
| 冬季雪天 | 20.201 → 3.589 ms | 22.00 → 4.20 ms | 34.60 → 7.50 ms |

独立普通绘制窗口观察到均值 **18.625 → 3.465 ms**、P95 **20.70 → 4.10 ms**、峰值 **34.70 → 6.60 ms**，本机FPS **42.47 → 108.77**。这是当时浏览器调度与负载下的观察值，不是玩家设备的固定帧率承诺；双绘制实验的FPS不代表产品FPS。

第14项以第13项为基线，实际连续移动镜头：

| 场景 | 均值：旧 → 新 | P95：旧 → 新 | 峰值：旧 → 新 |
| --- | --- | --- | --- |
| 拖动 | 9.619 → 8.336 ms | 11.70 → 10.20 ms | 14.60 → 13.70 ms |
| 缩放 | 9.545 → 8.212 ms | 11.60 → 10.20 ms | 14.10 → 12.50 ms |

独立拖动窗口均值 **10.951 → 9.587 ms**、FPS **58.49 → 57.90**基本一致。FPS受requestAnimationFrame调度影响，**以整帧脚本及绘制的平均值、P95作为主要指标**。P95表示95%的样本耗时不超过该值。上表统计CPU绘制，不包含模拟、浏览器合成和GPU完成时间。

## 比较条件与一致性

- 基准为v1.2第742天默认存档，普通模式、全图、晴天10:35。运行、夜晚、雨雪另测，雪天使用第767天。世界2560×1920，内部Canvas1152×816，全图缩放0.425。
- 用户显示画布1410×998.15；实际QA显示1410×998.75，内部尺寸相同。配对采样12秒，剔除前20对，交替绘制先后顺序。
- 固定时钟PNG与最初版本逐像素一致。前13项累计复验324组、第14项100组PNG及完整状态检查均无差异；相关失效测试和完整冒烟通过。
- 缓存只保存派生数据，不量化湿度或连续季节颜色，不降低分辨率或动画频率。正式默认存档与玩家缓存保留。

各项缓存失效条件、复现方法、完整测量与限制见[性能优化细节](性能优化细节.md)。未采用候选不计入上述成果；项目文档只记录实现、结果与判断，探索资料独立本机归档。

## 本轮收尾

最后评估了“相同可见格范围的分组复用”两种原型，共2503对样本。复用原画笔反而略慢；直接提交只减少0.071–0.227ms，拖动复测仅减少0.119ms，绘制P95没有改善，未达到明显收益门槛，因此没有采用。判断依据是总耗时与P95，不是FPS。

当前14项优化均已验证，没有未完成生产改动，**已停止并删除每小时续作任务**。今后出现新的实际卡顿场景时再采样定位。候选测量与限制见[性能优化细节](性能优化细节.md)。
