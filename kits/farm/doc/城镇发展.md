# 苔谷：旅人与公共发展

[世界与玩法](世界与玩法.md) · [村庄建设规则](村庄发展.md) · [v1.2 版本说明](../logs/v1.2.md) · [代码结构](代码结构.md)

本文记录 v1.2 的旅人与公共生活。v1.0 默认存档保持原样，已有浏览器存档或默认存档加载后补齐城镇状态，其他进度继续保留。

旅行商人、公共预算、设施改善和生活互动最初在 [v1.1 开发阶段](../logs/v1.1.md) 完成，现已纳入 v1.2。初始区域、施工队、道路与房屋建设、居民迁入和存档接入见 [村庄发展](村庄发展.md)。阿棠需在旅人驿屋建成、积蓄至少 5000 金后择日来访，不提前借住或营业。欢庆活动需等广场建成；下文的设施互动需要对应基础工程已开放。

## 旅行商人阿棠

**旅人驿屋完工且积蓄至少 5000 金**后，阿棠把苔谷加入行程。普通日的清晨或上午，他从地图东侧推着小货车进村，停在旅人驿屋院子里。普通来访持续两个普通日，欢庆日另加一天；接了施工委托则留到完工。离开后间隔四至七天再择日来访。下一次停靠时也需要至少 5000 金积蓄。上午已经过去或当天是欢庆日，就等合适的下一天，不会瞬间出现。

商品按**本次来访开始时**的金币确定，来访期间不会因收入、购买、刷新或重新导入而换货；每件本趟限购一次，价格在基础价格上下约 10% 浮动。

| 来访时积蓄 | 新增可售商品 |
| --- | --- |
| 5000 金 | 野鸟谷粒、山谷花茶、四季花种、猫咪绒球 |
| 20000 金 | 手作风铃、暖光纸灯、溪鱼陶盘、旅人共用布伞 |
| 100000 金 | 蜜源花籽、溪畔巢箱、林间木雕、旅人写生册 |
| 500000 金 | 木制音乐盒、彩晶标本 |

每趟从仍有库存空间的商品中随机带来最多五件，优先一件当前财富阶段的商品；该阶段收齐后从其他可用商品补位，全部满库存时仍会带故事来访。晚间收摊，绕过货车沿院边小路回驿屋。欢庆日停工，和大家一起过桥到广场，傍晚直接回屋，次日从屋门出发。

驿屋茶桌南侧保留草地，不再铺设第二层绕行支路。阿宁和阿葵沿上侧村路、货车东侧车道及南侧横路到茶桌；经过村口右上路灯时从道路内侧绕开，再回到货车顶棚以北的行走线。返程及阿葵茶会后直接回家的路线复用同一避让。阿宁最迟在 15:36 开始返回；花茶与茶点共用这一截止时间，保证实际到座后有时间享用。阿棠外出修缮直接沿南侧横路接入村口主路，豆豆从该横路进入院内草地，夜归沿车道回屋。

点击阿棠或货车可打开地图里的货架，**全屏纯享模式同样能购买**；侧栏「旅人与小镇」也列出库存、价格和购买按钮。未营业、该商品已售、储存已满或购买会侵占经营储备时，按钮不可用。悬停可查看商品的实际用途。

### 午后小歇

普通日没有建设或养护委托、雨雪强度低于四分之一时，阿棠在 12:14—13:41 之间每天有一次 45% 的小歇机会。选中后实际走到驿屋茶桌旁的椅子；到座才取用一杯已经买来的花茶，没有花茶也能坐着歇脚，不再收钱。小歇持续 3.2 秒世界时间，随后走回货架继续营业；途中或坐下后遇到明显雨雪，也会回柜。到座前取消不消耗花茶。离柜期间界面说明暂歇，购买和接委托暂停。

当天已选择的日期、移动路线、喝茶标记与剩余等待时间随完整存档保存，刷新不重复抽选或消费。自用花茶单独累计，侧栏、悬停和完整账本可查看；它不计入招待客人的杯数。暂停只有原地蒸汽继续，移动、等待和取茶冻结；夜归与欢庆优先。

## 公共预算

默认「稳步发展」。每个八天季节开始时，按照当时可用积蓄规划自动预算；分配预算不扣钱，只有实际采购才扣款。单季自动预算最高 15000 金。

| 模式 | 可用积蓄比例 | 行为 |
| --- | --- | --- |
| 手动安排 | 0 | 玩家自行购买 |
| 节制发展 | 3% | 小额自动添置 |
| 稳步发展 | 6% | 默认日常安排 |
| 热闹发展 | 10% | 更多添置空间 |

经营储备为 **600 金与全部主场田地按最贵种子播一轮的费用，两者取较大值**。手动和自动购买都保留这部分金币。每个营业日自动采购最多一件有用且预算足够的商品；消耗品只在余量较少时补货，永久手作有数量上限。改预算模式保留本季实际已花的钱；切回旧模式不会重置支出。

手动购买不受自动预算额度限制，但仍保留经营储备。采购支出、照料补给、建设支出与累计总数均随存档保存。「旅途见闻」保留最近十二条，超出的显示区域可以滚动；界面默认展开。

## 买来的东西会发生什么

- **野鸟谷粒**：每次补四份，最多八份；晴好白天吸引一只小雀，实际落盘后才取一份，每天最多一次。下雨、下雪或傍晚，鸟儿沿原方向飞走。
- **山谷花茶**：每次补四杯，最多八杯。有花茶且阿棠营业时，阿宁在普通日的早晨有机会过来听故事、喝茶，再沿村路回家。来回避开集市、路灯，回家速度沿用原来的规则；每次真正喝茶才消耗一杯。
- **四季花种**：在驿屋门前添花盆，约 1.2 个游戏日内逐渐长高、开花；颜色沿现有季节过渡连续变化，最多三盆。
- **猫咪绒球**：广场猫屋附近出现最多三个小玩具，两只猫更愿意走到这一角伸懒腰、歇脚，雨天仍然留在家里。
- **手作风铃**：驿屋檐下出现轻轻摆动的风铃。
- **暖光纸灯**：依次为驿屋、阿森和阿矿家门边添灯，入夜渐亮，点击可免费调柔光。
- **蜜源花籽**：丰富西南既有野花带，不占苗床或道路；约 1.2 天逐渐生长，花株长大后暖季晴天会有两至四只蝴蝶来访，傍晚渐渐离开。
- **溪畔巢箱**：在西南小湖与湿地之间添巢箱和浅水盘。晴天有概率来一只翠鸟，在巢箱歇脚，飞到小湖水面觅食，再返回巢箱；傍晚离开。停栖绘制在巢箱前，飞行进入空中层。
- **木制音乐盒**：摆在驿屋茶桌，阿宁喝茶或阿棠坐下小歇时，会有轻轻跃动的音符。

暂停冻结来访、路线、预算决策、觅食与消耗；人物挥手、风铃摆动、鸟翼和蝴蝶翅膀等原地动作继续。商品、随机种子、每日选择、居民位置、货车是否连接、茶会路线、鸟蝶位置和飞行目标全部保存，刷新不会重抽或回到起点。

## 有过程的公共设施

这里是阿棠原有的改善项目。施工队负责的大型基础设施与驴驿配套道路，见 [村庄发展](村庄发展.md) 第 3 节；必要设施未建成时的委托限制见该文第 10 节。这些 v1.2 前置条件已接入委托与自动采购，不改变本节小型改善的原费用。驴驿先有配套道路，茶亭改善先有南谷茶亭，庭院改善先有旅人驿屋。

阿棠营业时可以委托，每次只进行一项。材料和手工费在接单时一次扣款，不按天重复收费。工地从木料、框架逐渐变成设施；施工进度、往返路线和已经完成的阶段全部保存。

| 设施 | 首阶段积蓄门槛 | 首阶段费用 | 三个阶段的变化 |
| --- | --- | --- | --- |
| 猫屋舒适角 | 5000 | 380 | 遮雨棚内软垫、加厚软垫、浅水碗 |
| 溪畔鸟类驿站 | 7000 | 620 | 巢箱、遮雨帽与台阶、岸边小花 |
| 西南蜜源花园 | 10000 | 750 | 分三次丰富野花带、吸引蝴蝶 |
| 茶亭风铃与花架 | 18000 | 1100 | 檐下风铃、第一盆花、第二盆花 |
| 东岸旅人花园 | 25000 | 1500 | 每阶段添一排花株，保留草地间距 |
| 东岸小驴驿 | 50000 | 2200 | 驴棚与麦穗 → 遮雨水槽 → 豆包入住 |

猫屋舒适角位于原猫屋右侧，棚顶与猫屋屋顶近乎齐平；软垫只有一块，放在棚内。猫咪沿空地走到软垫休息，回屋仍走原路线；图形、落脚点、施工和悬停共用布局坐标。

每项最多三阶段。已有阶段数为 `L` 时，下一次费用为基础费用 × `(1 + 0.7L)`，四舍五入；积蓄门槛为首阶段门槛 × `(1 + 2L)`。保留经营储备，自动委托还受公共预算限制。自动发展每趟商人最多接一项。可负担的建设先比较阶段数，同阶段优先最近一次建设日期较早的设施，仍相同时比较费用；新地点也在此顺序内。玩家仍可在完工后的营业时间追加委托。

阿棠沿道路过桥赴工地，下午沿来路回驿屋；茶亭较远，会提早出门。下雨、下雪降低施工速度，夜间与欢庆日停工。天气、路程与欢庆安排都会影响工期，因此目录中的工作量不等于固定日历天数。已经支付的委托会继续完成，改为手动预算不会取消它。

花园和花盆以各自种下的日期连续生长。新增阶段不会让之前的花退回幼苗，暂停不推进生长；刷新和导入保持原来的阶段与长势。手工装饰使用统一接地点排序，附在屋檐上的风铃与建筑一起绘制，巢箱前的翠鸟仍显示在巢箱前。

## 季节照料

已建成的设施随着时间和风雨增加照料需求，范围为 0—1：每天基础增加 0.012，过去一天的雨雪强度分别再增加最多 0.015、0.01。每天只结算一次，刷新不重复积累；未建设的地点没有养护开销。达到 0.25 可手动请阿棠整理，达到 0.5 时小镇才会考虑自动安排。

一次养护费用为 **设施基础建设费 × 18% × 已有阶段数**，四舍五入。例如三阶段东岸花园为 810 金。只在接单时付一次费，沿用公共预算和经营储备；花园使用浇水壶，木作使用整理工具。工具会摆在工地，阿棠实际沿原道路往返。工作量比新建小，仍受天气、夜晚与欢庆安排影响。

自动委托先检查照料需求达到 0.85 的地点，再考虑建设；**连续两趟自动养护后，只要有可负担的建设，就给建设一次机会**。如果积蓄、预算不足，或所有设施已满三阶段，仍可继续安排养护；不会为凑顺序强行扣款。没有可建阶段时再考虑需求达到 0.5 的一般养护。施工和养护共用每趟最多一次自动委托的限制，避免商人一直留下工作。连续养护标记在成功自动接单时累积，最多记到二；成功自动建设后清零。未接单、刷新、跨日和商人离访保留标记，手动委托不改变自动顺序。侧栏与纯享货架显示安排参考和原因，只读取状态；接单前仍按当时预算重新核对。养护完成后需求清零，记录完成日期和累计次数；原来的等级、种植日期、植物长势与生态效果保留。**延后照料不会损坏或拆除设施**，手动预算也不会自动扣钱。

## 花园里的偶遇

- **冬日知更鸟**：冬季过渡超过一半后，晴朗营业时段的鸟食有 65% 概率引来暖棕色知更鸟，其余仍是小雀。实际落盘后一天只取一份谷粒，知更鸟在驿屋浅盘停栖，不进入翠鸟的潜水逻辑；雨雪或傍晚飞走。
- **雨后蜗牛**：东岸花园第一排长大后，在暖季草地里有机会出现两只蜗牛。当日或前一日有雨，机会为 70%；其他日子为 20%。它们只在花园南侧湿草里慢慢爬行、停留，中午后沿草地返回叶堆。
- **秋日刺猬**：秋季过渡超过一半、已有成熟花园时，每日 45% 概率选择晚间来访。黄昏从叶堆走出，寻找小虫，深夜返回。它与白天的蜗牛共用安静草地，不占道路或菜床。

早晨只决定一次当天花园访客，结果保存；没有访客的日子也不会刷新重抽。它们不增加作物产量，不吃掉玩家库存，不参与欢庆停工，继续按野生动物的日程活动。

点击小雀、翠鸟、知更鸟、蜗牛或刺猬可以安静观察。每只本次访客最多记一次偶遇，记录出现在「旅途见闻」和偶遇累计中；蜗牛会短暂缩回壳里，随后继续行程。暂停不推进位置、消耗、随机选择或缩壳时间，触角与翅膀等原地小动作仍继续。叶堆和动物以各自接地点排序，飞鸟保留空中层。

## 沿途招呼与旅行故事

普通白天阿棠在营业或沿路施工时，遇见 64 像素内正在活动的居民，会互相挥手。每人每天最多问候一次，每天最多三位，两次招呼间隔一小会儿。人在家里、阿棠已回屋、欢庆日或暂停时不触发。问候只改变挥手反馈和见闻，不替换工作任务、位置、货运计划或通勤路线。

每趟来访从当前季节的两段原创小故事中选一段，一共八段，结果随本次库存一起保存。阿宁喝茶时会听这一段；玩家可在侧栏或全屏货架点「听阿棠讲故事」，不收费，本趟只记录一次。听过后故事仍可阅读，刷新不会换故事或重复记听完；下一趟才重新选择。当天遇见的居民、问候等待时间和玩家是否听过故事同样保存。

## 沿路带花茶到南谷

阿棠受托修建或养护茶亭时，从驿屋已经买来的花茶中顺带最多两包，按茶箱剩余空间取用。装包时驿屋库存减少，沿途在他的随身包中保存；走到茶亭并开始工作后，才把茶包交付到茶箱。小茶箱最多四包，位于茶亭东南侧，避开茶桌和椅子。

若因工时结束而在交付前返屋，未送到的茶包退回驿屋；库存满时剩余茶包继续随身保存。搬运不另收钱，茶包费用已经在购买商品时结算。暂停不会交付或消耗，欢庆日按原来的安排停工。

阿矿原有的每四天一趟送矿、归还矿车、到茶亭歇脚行程继续运行。茶箱有花茶时，每趟只取一杯，计入茶亭和城镇招待总数；没有花茶时照常坐下休息。首次取用按送矿行程的出发日记录，刷新、长时间坐着或跨日都不会再取一杯。箱内库存、随身茶包和取用标记都随完整存档保存。


## 欢庆散场前的纸灯

广场建成后，每逢第十天的欢庆日，积蓄至少 5000 金时，35% 概率安排纸灯小会；结果在当天首次世界更新时保存，未安排的结果也不会刷新重抽。15:36 起至 16:19 前，天气晴朗或多云、公共预算足够且经营储备充足时，自动点灯一次。雨雪则等待，超过时段不扣钱。原来的清晨欢庆筹备费继续独立结算；纸灯属于额外可选公共活动。

玩家也可在欢庆日 15:07 至 16:19 前主动举办。点击广场木台只打开费用面板，点击面板内的举办按钮才付费；全屏同样可用。按当时金币的 5000 / 20000 / 100000 / 500000 阶段，分别点亮 3 / 4 / 6 / 8 盏，每盏 35 金，总价 105 / 140 / 210 / 280 金。每次欢庆日最多举办一次，手动安排不占自动预算，但仍保留一轮种植费及至少 600 金。
