## 探索农场各区域

主场未开垦的区域保持草地；作物只出现在已开垦且已种植的田格中。

完整世界有 **2048 × 1920 像素**，主画面采用较宽的 **1152 × 816** 视窗，一次只显示其中一部分。东侧容纳完整的河东村口与北岭林地；南侧新拓出一片山谷，容纳牧场与临河休憩地。按住主地图拖动可四处探索；侧边小地图中的亮色方框是当前视野，点击或拖动小地图可快速前往。普通视图的地图缩放范围是 **70%—160%**；全屏纯享模式可继续缩小，直到完整地图刚好放进屏幕，一组对边贴住屏幕，另一组对边在屏幕内居中，此时无法再缩小。全屏缩小下限随屏幕比例与窗口大小调整。可用侧边按钮、滑杆、主地图鼠标滚轮或键盘 `+` / `-` 调整。缩放会尽量保留当前视野中心；滚轮缩放以鼠标所在位置为中心。“回农场”可返回主场。方向键或 `W A S D` 也能平移。

地表由连续的噪声纹理决定颜色，森林、草甸与村口的交界会自然过渡；小草与花朵单独叠绘，泥路使用连续的路带和柔和边缘。右侧溪流、四座木桥与小地图使用同一套坐标；河岸与水底保持稳定，浅色水纹沿河道自北向南缓缓漂移，经过木桥时从桥板下穿过，暂停后水纹也会停住。道路连接桥头、各处货箱及主场小屋，东部森林与村口之间有一条避开树丛的小路。旧牧场的位置成为河西的苔谷广场，河东则是小屋、喷泉和货摊组成的村口街区。广场向北、向西展开，与左右道路都留出相近的草地边距；两条短径通往主路。南谷牧场与茶亭另有散步小径。东侧风车位于牛舍右上方，旋转叶片与筒仓、林间木屋留有间隔。地表和蘑菇野莓等采集物先绘制；村民经过建筑与树木时，按脚下位置决定前后。牛、羊与山羊在围栏后侧的前面行走，走近画面下方时仍会被前侧栏杆遮住。阿栀采摘时会显现在香草前方；猫头鹰单独绘在树冠前方，停枝时也能看清。

- **苔谷主场**：农舍、牛舍、鸡舍、果园、池塘和原有田地。
- **东部森林**：林间木屋、松林、溪流与木桥。每天会在几片林间空地随机长出 **7—10 处**蘑菇或野莓。每一处都能单独采摘，采完就从地图消失，次日重新生成；蘑菇送到村口后卖得 18 金，野莓放进果篮。溪流东岸的北岭空地有觅食的小鹿、在灌木间蹦跳的野兔，以及会在树间巡飞的猫头鹰。野兔区域左侧的青榆有清晰的深色树冠边缘和柔和的黄绿色叶片，蓝杉留在右侧；白桦移到溪流东岸、小路北侧，红枫位于更东边的北岭。猫头鹰每天夜里只巡飞一次，从当前树枝飞向老松、白桦、红枫、蓝杉或青榆中的另一棵，落下后一直留在那里，白天与大雨也不会强制返回老松。点击猫头鹰可以看它在当前树枝附近展翅，随后落回同一棵树；它飞近时野兔会躲起来。点击小鹿或野兔，也可以看到它们各自的反应；鼠标移到落脚树上能看到提示。采集点会避开动物路线和树下。守林人 **阿森**住在已有的林间木屋，每个普通日早晨只选择一次日程：**50% 采菇、50% 巡林**。采菇日最多采三朵森林里已有的蘑菇，采完优先直接前往下一朵，收成进入森林采集箱；没有可采蘑菇或已采满时，转为巡林。野莓和橡果留给玩家。巡林时会到松鼠、小鹿和野兔附近停步观察、挥手，动物会转向或短暂停留，不消耗玩家的果篮。路线避开树干、木屋和河水，去东岸走北桥。夜里回木屋，欢庆日停工去广场，当天不选择采菇或巡林；下一普通日清晨重新选择。当天选择、已采数量、采集进度、位置和行走路线均随完整存档保存，刷新不会重选日程或重置收获。
- **西湖**：位于主场西南、湿地苗圃以北，与上方田地留有宽松的草地；栈桥、钓鱼小屋、鱼箱支路、岸边树木与水草围绕湖岸布置。湖边有系泊的小船、芦苇、睡莲和两只自由游动的水鸭；暖季还能看见岸边青蛙与蜻蜓，湖水颜色会随冬季渐变。每天出现 **3—4 处**发亮的鱼点，每处能单独点击垂钓；钓走后消失，次日换位置。鱼先进入西湖鱼箱，送到村口后普通湖鲤卖得 24 金，较少见的金鳞鱼卖得 42 金。点击水鸭，它会应声游开并划出波纹；夜晚水鸭向岸边靠拢。阿蓼每天白天从实际鱼点自动钓 **1—2 尾**鱼，上午约 08:53 开始第一轮，若有第二轮则下午约 14:10 开始；每轮有抛竿、等待与提竿过程，收获进入西湖鱼箱并计入垂钓账本。玩家先钓走正在等待的鱼点时，他会重新寻找鱼点，不重复收获；鱼点不足时不额外生成鱼。完成当天数量后留在栈桥看湖景，入夜步行回钓鱼小屋。欢庆日停钓赴会；暂停冻结垂钓进度，当天数量、目标和等待进度随完整存档保存。夜里桥头灯点亮。
- **南方牧场**：金币达到 **1200 金**时自动投入 400 金，在山谷风车南面开放羊舍并开辟 **32 格（8 × 4）**新田地；下方田地向右、向下各增加一格，仍与道路和湖泊留有草地间隔，迎来两只绵羊。羊群会散步、夜晚归栏，每三天可梳一次羊毛，收入 72 金。羊舍开放后，其东侧才会出现山羊舍的待建木料和木桩；金币达到 **1500 金**时投入 300 金建造山羊舍。建成后，糯米和栗子白天在围栏里散步，雨大或入夜会回到棚边，点击可让它们蹦跳。阿牧在两舍间歇脚，牧场货箱靠南侧道路。
- **苔谷广场**：河西的交通中心，范围为 **522 × 352 像素**，向四周扩展、北侧多留空间；东北角收边，避开森林货箱支路。暖木台靠北，水井位于木台右上方，与花圃留有间隔；茶点桌在两侧，长椅在南侧，中央铺地与外围草地自然衔接。东边与南边各有一条入口短径，小地图和悬停提示复用设施坐标。每逢第 **10、20、30……天** 举办欢庆日，阿满、小禾、阿青、阿麦、阿栀、阿牧（开放牧场后）、阿运、阿宁、阿蓼、阿葵、阿芽、阿矿和阿森停工赴会。大家会轮流取餐、聊天、观看木台、坐下喝茶和跳四季小舞；活动点各有名额，同时最多四人在广场内部走动，短路线避开餐桌、水井、长椅及其他居民。预算充裕时增加木台前演奏与中央舞会，居民面对邻居聊天，观众朝向木台，坐下休息时面向画面。春天是「春花集」，夏天是「夏日小乐会」，秋天是「秋收分享会」，冬天是「冬日暖茶会」。约 16:34 收场，大家从当前活动位置走回入口，再沿通勤路线各自回家。彩旗挂在两根落地木柱之间的下垂绳上；盛大庆典增加灯串，暮色中发出暖光。家具和居民按脚下位置绘制前后关系，暂停只冻结移动和活动进度，仍保留原地小动作。

- **西南湿地苗圃**：西南小湖以南的湿地区域扩展到原来长宽的约两倍，并稍向南移。从小湖流出一条浅溪，经过向西退开的溪畔观鸟台，再从一座小木板桥下穿过野花草甸，汇入湿地；浅溪、观鸟台、木桥与湿地水面从第一天就可见，不依赖苗床开放。西南草甸成为连绵的湿草地、泥岸、西侧水潭和东南侧两处浅水洼；雨水让水潭与小洼缓慢涨落，外围湿草渐深，而非整片变成深水。水边分散生长芦苇、香蒲、莎草、鸢尾和睡莲：香蒲秋冬变色，鸢尾在暖季开花，睡莲随水位舒展叶片并在白天开花。青蛙会跳进水里，黑水鸡常年在睡莲间缓游；暖季晴天有蓝尾蜻蜓巡飞，暖夜可见芦苇间的萤火虫，雨天昆虫会暂时藏起来。点击黑水鸡或飞虫会引起短暂的游动、转向与闪烁，悬停植物可查看习性。阿芽从第一天就住在这里；首批苗床修复前，平日留在小屋，欢庆日仍去广场。农场累计送达 **100、200、300 件**货物时，村里依次修好 **4、7、10 畦**旧苗床；新苗床的木框与花苗逐渐显现，修好后立起区分花束苗和种子苗的小木牌，刚播下的种子也有浅色种植标记。阿芽白天逐畦采收，收完一畦会优先选择最近的可采苗床，沿苗畦间的空隙直接前往；所有苗床都未成熟时才去长椅，新有苗床成熟也会及时返回采收。闲时沿苗畦间的草地走到小路北侧长椅，夜晚回家；玩家也能逐畦采收。野花束和种子包进入苗圃右上角、紧靠主路的货箱。苗圃开放后新采下的香草再生时间缩短约一成；修好第二阶段后，暖季果园每两天也会有一篮水果。冬季花苗生长较慢，雨天较快。苗圃加成不消耗种苗库存。旧版六畦存档导入后保留原苗床进度，新添苗床独立开始生长。
- **西南小湖**：西湖以南、湿地苗圃以北的小水域有会游动和潜水的水獭、缓慢巡游的乌龟、在东岸浅滩踱步的苍鹭，还有一群游动的小鱼。鱼群会在水獭接近时散开，稍后重新聚集；点击鱼群也会让它们短暂散开。点击水獭会看到潜水泡泡，点击乌龟它会缩进壳里，点击苍鹭它会振翅移向另一丛芦苇。雨大时水獭靠岸、乌龟缩头、苍鹭避雨；夜晚它们各自往固定的休息处移动。小湖还有芦苇、睡莲、岸石和蜻蜓；这些生物从第一天就能遇见。
- **南方山谷**：山谷风车与溪流之间有六畦香草梯田，种着薰衣草、薄荷和百里香。每株都能单独点击采收，采后会从嫩芽逐渐长回，其他植株不会受影响。一般约两天再生；雨天约一天半，寒冬约三天。香草送到村口后每株收入 16—22 金，采摘进度与累计株数会随完整存档保存。扩展后的东南山谷有木制茶亭、冒着热气的茶壶、花丛与临河观景台；晴暖白天有蝴蝶，夜间有萤火虫和逐渐亮起的两盏暖灯。沿牧场西侧小径向南便可到达，新景物从第一天就能探索，小地图也会显示位置。
- **河东矿坡**：南桥东岸道路向南分出支路，通往地图右下角的暖灰色岩坡。阿矿的小屋西移到矿区西北草地，门朝东开；屋门右侧的东西路与南桥来路接成丁字路口；到村口右侧矿摊的道路从东岸菜圃东边绕行，不穿过菜畦。五处露天矿脉分别出产青石、赤铜和月白石英，采过后岩块会由碎石逐渐显露；玩家可逐块点击采集。矿洞入口接到从北往南数第三条向右的采矿支线，轨道先向东，再转向北进入洞口；原矿洞支线改成月白石英矿脉。左支线尽头是阿矿的歇脚台。阿矿白天沿轨道采矿，采完一处若还有可采矿脉，直接去下一处；都采完才去轨旁歇脚。普通采矿日早晨若没有可采矿脉，他也会从小屋沿道路与轨道前往歇脚台，等矿脉恢复后再去开采，夜里沿路回矿屋。矿石先存矿区棚屋；阿矿连续采矿三天，第 4 天从棚屋对面的路东侧取推车，把出发时的库存送到村口右侧摊屋；送货当天不采矿，售完先把空车推回棚屋对面的停放点，再经原来的南桥去茶亭边的小桌坐下喝茶约七秒，从茶亭北路往东走过新建的南侧小桥，经丁字路口直接进屋休息。卖出的收入计入农场金币与矿业账本，但矿石不进入阿运货车或作物订单。若预定送货日恰逢欢庆日，矿石留在棚屋，阿矿从矿屋过南桥去广场，傍晚原路返家；次日补送，下一次从实际送达日再隔三天，在第 4 天出发。矿脉状态、库存、收入、阿矿的位置、货物和路线都随完整存档保存。
- **村口街区与集市**：越过木桥到河东，可看到三间民居、喷泉、告示牌、货摊和东岸菜圃；这片街区与集市属于村口，不再称作广场。三间民居的夜间窗光跟随房屋坐标；街区右上、右下、左下各有一盏路灯，灯柱与运货路线留出间隔。西侧第一间民居是阿运回村后的落脚处。阿宁是村里的孩子，像素画保留较小的身形和清楚的双手、眼睛；白天沿阿运与自己两间小屋门前的空地往返散步，从一处门廊走到另一处，这条路避开阿运车道与集市摊位。夜里按原来的归家步速走回第二间小屋睡觉。悬停可看到名字和动向，点击可打招呼；散步位置也随完整存档保存。开市后两个摊位都位于喷泉两侧，不会被河流分隔。金币达到 1900 时投入 600 金开市；此后作物出售价格提高 15%。
村口右侧矿摊从第一天就备好空木箱，收到阿矿送来的货时陈列矿石；左侧农产摊仍在正式开市后开放。

牧场西侧的南北路沿用主路宽度，通往茶亭的东西路与南桥道路等宽，转角连续衔接。茶亭和观景台再向南移三格，与道路间留下草地；观景台旁的树也向西移开，南侧保留散步和观景的空间。

## 广场的日常小动物

广场平日有橘白猫 **橘子**、奶牛猫 **墨点**，以及间歇飞来的 **3～5 只麻雀**。双门猫屋位于广场西北侧与牛栏之间的草地，和围栏、广场边界留有间隔，旁边放着水碗与食碗。

- 猫从早晨出门，在广场散步、晒太阳、洗脸、伸懒腰，也会坐着观察麻雀；两只猫独立选择休息点，路线避开木台、水井、花圃、长椅与欢庆桌。**雨天不出门**；正在外面的猫会沿路回屋，夜里也回家。没有额外产物、金币消耗或货运。
- 麻雀白天分批飞来，停在空地啄食、短跳、整理羽毛；井沿、木台边、长椅和猫屋屋顶也可以落脚。居民或猫接近地上的麻雀时，它会飞到高处；欢庆日优先落在高处，也可停在彩带木柱顶。雨天和傍晚离开，夜里不在广场停留。
- 悬停可查看猫的名字、毛色和动作，或麻雀的活动；点击猫会喵叫、蹭手，点击麻雀会换个落点。悬停猫屋可查看两只猫是否在家。
- 暂停时位置、路线和行为进度冻结，摆尾、眨眼、洗脸与整理羽毛仍有原地动作。两只猫和每只麻雀的位置、目标、路线、停留时间、飞行进度与互动状态都随完整存档保存；当前存档未包含它们时，从猫屋与场外初始化，不影响农场原进度。

## 各区域的货物流通

村口最右侧、第三间小屋是阿葵的家。她平日清晨先出门到集市北侧通道，向西走到告示牌旁，再转向南抵达工作处，夜里沿反向路线回家，避开两侧摊位与喷泉；通勤途中不会提前转去菜圃。她在告示牌旁整理委托，也会沿村路去东岸菜圃照料蔬菜；欢庆日从小屋出发，到活动结束后沿原路回屋内休息。阿蓼则从西湖钓鱼小屋出发，返程回小屋，不会留在栈桥上等到夜晚；平日清晨和傍晚也会在小屋与栈桥之间步行。其他参加者抵达各自住处后也会进入屋内。欢庆日后的次日清晨，大家先留在家里，再从各自家门口步行出发；阿运从村口西侧民居走到集市出发点，阿葵走到告示牌，阿蓼走到栈桥。

东岸菜圃有 **28 畦**村民自用的蔬菜：青菜、小萝卜、豆荚、番茄、小南瓜与卷心菜随季节轮作，各畦错开生长。两排菜畦之间留出 **28 像素**宽的贯通小路，上排向北稍移，下排仍与南侧道路保留一格草地。阿葵每天最多照料五畦，成熟的逐畦采收并补种，未成熟的浇水；照料上排时转身向北，照料下排时面向南，人物绘在上排作物之前、下排作物之后。雨天也会给菜畦补水。收成存放在菜圃右侧唯一的村口菜篮，供村民日常取用；每逢欢庆日，菜篮里至多十二份蔬菜会摆上广场餐桌。悬停菜畦与菜篮可查看作物、长势和存量。菜圃是村民的生活部分，不产生农场金币、不完成订单，也不进入阿运路线和农场账本；它的菜畦、菜篮与阿葵的照料进度会随完整存档保存。

欢庆日会暂停村民工作与货运。阿运若在村口且次日是欢庆日，会在前一天留下休息，不开始需要两天的新行程；活动当天从村口前往广场。若因旧行程仍在农场一侧，当天会在农场小屋休息，次日继续原来的货运计划。阿矿的送矿只占一天，因此无需提前休息：当天停止开采与送货，矿石留在本地，次日再送。货箱里的物品仍会保留。玩家手动暂停欢庆日时，村民留在原位继续原地跳动、挥手，路线与农场时刻保持静止。
羊舍开放后，羊圈西侧会留出通往南北主路的短径与围栏出口，阿牧参加广场活动时从这里步行出入。

森林采集箱位于森林南端道路东侧、靠河的北部空地，离开广场北缘；阿运从主路转入短支路收货，再回主路向北走，货箱内容及返程规划规则不变。主场、西湖、湿地苗圃、牧场、山谷与森林各有一个暂存货箱；苗圃货箱随首批苗床出现。主场货箱放在主场道路北侧的草地上，货车从路边装货。阿满、小禾、阿青和阿麦共同处理主场农务：种田、收鸡蛋、挤牛奶、摘水果和收蜂蜜。主场收成进入主场货箱，南部新田地的作物进入牧场货箱。阿麦从第一天加入，住在主场农舍，穿浅橄榄色上衣；夜里返家，欢庆日与大家一起赴会。现有已开垦存档会补齐新增田格并保留原田地作物和任务进度。羊舍开放时阿牧加入，专门收集羊毛和山羊奶，放入牧场货箱；没有工作时走到两舍之间的长椅休息，夜里回羊舍。悬停可看村民姓名与职责，点击可向村民打招呼。阿栀从第一天就照料山谷六株香草，成熟后逐株采下放进山谷货箱；白天闲时在风车右边、香草田左边的摇椅上休息，出门沿风车南侧直接往右走到香草田，夜里循原路回左边的小屋睡觉。原本挡在摇椅旁的松树略向左移，留出椅子与香草田的间隔。玩家和阿蓼钓到的鱼进入西湖鱼箱，玩家采到的蘑菇与橡果以及阿森采到的蘑菇进入森林采集箱；野莓仍留在果篮里，可喂松鼠。

阿运的运货往返跨越两天。第一天去程不规划收货地点。第二天返程正式出发时，统一检查主场、西湖、湿地苗圃、牧场、山谷与森林这六处货箱，把当时有货的地点定为本趟收货路线；森林箱有货便安排森林绕行，无货则走中央木桥。返程出发后，整趟路线保持不变；未列入计划的货箱即使随后新增货物，也留到下趟运输。抵达计划中的任一货箱时，会取走箱内当时的全部货物；途中货箱变空也不会临时改道。第一天经中央溪流木桥沿路走到主场小货摊旁的小屋，不沿途收货。第二天按主场、西湖、湿地苗圃、牧场、山谷的顺序走访返程出发时有货的货箱；牧场箱位于香草箱西侧，因此沿南路从西向东顺次收取，不必回头。返程出发时为空的支路会略过。如果返程出发时森林箱有货，他继续沿森林支路、北桥返回，然后从青榆西侧南下，在民居北侧转弯，从两间小屋之间进入村口；野兔活动的草地保持完整。没有森林货物则从中央木桥直接返村口。主场货箱在路边装货，湿地箱紧靠主路，其他货箱由短支路连接，阿运始终走在路上。他的脚程比原来快；到了晚上，若在河西就沿道路回到主场小屋的朝北门廊，若在河东就回村口西侧民居。睡下后不再显示在户外，天亮沿来路回到离开运货路线的地点，继续原有行程，货物与已定路线不会丢失。村口三盏路灯仍位于街区角落，阿运的停靠点与行车线避开它们。运抵村口后统一结算金币与作物订单；悬停货箱可查看品类和数量，悬停阿运可查看车上货量。小地图标出暂存点、支路与阿运的位置，完整账本记录待运货物和累计送达件数；待运明细每个地点单列，货物过多时在地点名称后换行对齐。集市正式开办前，村口也有简朴的收货点；开市后作物售价再提高 15%。货物、车上的载荷、返程出发时定下的完整收货路线、行程进度和夜间返家状态都随自动存档与 JSON 存档保存。

## 欢庆预算与共同消费

欢庆日清晨用当时的金币确定预算：`max(0, floor(min(金币 × 1%, 金币 − 300)))`。留足 **300 金**经营储备；不足时预算为零，大家仍举办家常聚会。每次筹备只扣款一次，当天后续收入不改变预算。

| 本次预算 | 规模与可见变化 |
| --- | --- |
| 0—49 金 | 家常聚会，茶水和简单点心 |
| 50—199 金 | 丰盛餐桌，增加糕点、水果和花束 |
| 200—999 金 | 热闹庆典，增加乐器和木台前演奏；约 11:17—13:41 是中央舞会时段 |
| 1000 金及以上 | 盛大庆典，增加丰盛甜点、木柱暖灯和彩灯串 |

右侧「苔谷欢庆」显示规模、本次支出、清晨金币和活动安排；普通日显示下次日期和按当前金币预估的预算，点击可定位广场。完整账本记录累计欢庆支出与筹备次数，日记记录筹备金额。预算按当天金币计算，不参考收入，也不从阿运货箱取货；东岸菜篮原有的欢庆分享独立保留。

清晨金币、预算、等级、已筹备日期和累计支出保存在农场状态中；每位居民的活动、已占位置、等待时间和内部路线保存在动态状态中。刷新、暂停或完整存档导入不会重复扣款或重新选择正在进行的活动。

## 一天如何度过

农场从早上 **06:00** 走到次日 **06:00**，1× 下一天约 56 秒，其中白天约 42 秒。白天正常流逝；**20:00 后自动加速到 2.1 倍**，但仍会完整经过黄昏、深夜和黎明。夜色会逐渐加深，农舍与路灯亮起，萤火虫出现，随后画面逐渐变亮。主场工人收工回家，阿栀回小屋睡觉，阿运走回所在河岸的小屋，阿宁回第二间村民小屋，牛牛和鸡群归巢。右侧还可以手动选择 1×、2×、4×，或暂停观察。暂停时日期、天气过渡和角色的路线位置保持不变；人和动物仍有原地的小动作，例如摆尾、眨眼、扇翅或轻轻点头。这里没有直接跳到次日的按钮。

每 8 天轮换一个季节。交界前后约 **3 天**，草地、树冠、花色、林地与冬季霜色会逐渐过渡，季节牌会显示“春 → 夏”这样的提示；跨过换季当天也不会突然换色。作物和天气仍按当天所属季节结算。换日后若天气变化，晨间约 **3.6 小时**内云影、雨滴或雪花会逐渐淡入或淡出，天气牌显示转变方向。冬天每天有约 **32%** 的概率飘雪；云影、雨丝与雪花在暂停时仍会移动，但当天的天气类型和淡入淡出进度随农场时刻停住。下雨时田地自然得到浇灌；冬季作物生长变慢，温室建成后恢复正常速度。

## 动物、订单与建设

- 两头牛牛会在围栏里散步，每天各产一次奶。点击牛牛陪它玩，牛奶售价会小幅提高。
- 鸡舍里有三只会走动的鸡。工人每天收集鸡蛋并出售；夜晚鸡群回窝。点击鸡群喂食也会略微提高鸡蛋售价。
- 果园在春、夏、秋每隔三天结一次果；工人会采摘出售，秋季售价最高。
- 森林松鼠会在树下与野莓之间来回奔跑，停下嗅闻，雨大时躲到树下，夜晚归巢。点击松鼠可打招呼；果篮里有野莓时会喂它一份，提高亲近度。每喂三次，它会带你找到一枚可采集的橡果。北岭的小鹿会停下低头吃草，野兔受惊会跳向另一丛灌木，猫头鹰则在夜里活动。
- 村民阿葵在告示牌维护一份订单列表。每份订单有自己的作物、目标数量、截止日和额外奖励；侧栏显示三份，更多的可在卡片内滚动查看。可以将其中一份设为优先种植；同类货物由阿运送达时，先分配给较早截止的订单，不会重复计入多份委托。已完成订单立即结算奖励；过期订单逐份移除，平时每隔两天还会补充新单，最多保留五份。欢庆日让已有且仍有效的订单统一顺延一天。
- 农场有足够收入时会自行建设：达到 **250 金**开垦东侧 **18 格**田地，**430 金**添置蜂箱，**680 金**建造温室并向主场南侧扩展 **10 格**田地，**1200 金**开放羊舍与南方牧场，**1500 金**建造山羊舍，**1900 金**开办村口集市。各块新增田地都与相邻道路隔着草地。每项建设会消耗一部分金币。两只蜂箱摆在果园西侧的草地上，离道路留有空隙；每两天酿好一罐蜂蜜，由工人收入主场货箱，鼠标悬停蜂箱可查看酿蜜周期和累计收获。

## 亲手参与

将鼠标移到地图上，可以查看当前位置的建筑、田地、动物或区域；左下角的西南小湖、西湖、池塘、河道与木桥都有各自的提示，提示文字会在鼠标静止时持续刷新作物长势、成熟状态、货箱内容及角色动向。原对象移出鼠标位置、采集物被采走或鼠标离开地图时，提示会消失；再次移动鼠标才选中新的对象。拖动、缩放和页面滚动后也会重新核对鼠标位置。点击地图可以与部分对象互动；西湖水面上的发亮鱼点能直接垂钓，侧边小地图会标出鱼点、小湖里的水獭、乌龟、苍鹭，以及北岭的小鹿、野兔、猫头鹰。地图下方的工具可切换“观察 / 播种 / 浇水”，播种时能选择五种种子。键盘数字键 `1`、`2`、`3` 切换工具，空格键暂停或继续。点击页面底部的“重新开始这座农场”可以清除当前进度。

桌面布局中，页面最大宽度为 **1800 像素**；宽屏新增的空间用于右侧信息栏，使其从 **320 像素**逐渐扩至 **370 像素**，地图宽度保持原有上限。右侧小地图、时间、账本等工具栏与左侧地图面板等高；更多卡片在右栏内滚动查看。窄屏时工具卡片排在地图下方，随页面正常滚动。小地图之后先放时间控制，再放独立的「苔谷近况」卡片：按森林、西湖、湿地苗圃、矿坡和阿运货运分组，显示资源余量与居民当前活动；回家、休息和欢庆状态与地图悬停提示使用同一套判断。点击区域名称可定位地图，点击「阿运货运」定位他的当前位置，定位会随视角保存。阿运本趟路线、北岭与小湖生态、松鼠亲近度和累计采集、钓获数字放在可展开的详情中，默认全部展开，仍可手动收起；近况卡片最高 420 像素，也不超过窗口高度的 65%，超出的内容在卡片内用滚轮或键盘滚动，标题保持可见。农场演变刷新文字时保持当前展开状态与滚动位置。

“农场小账本”默认显示金币、作物收获、当日牛奶与鸡蛋、田地和蜂蜜。点击“查看完整账本”可展开田地里的作物数量与成熟格数、牛奶和鸡蛋累计产量、果篮、羊毛、香草、森林采集与湖泊垂钓的分类统计，以及动物亲近度、区域待运货物与累计送达件数；再次点击可收起。橡果只有拾取后才计入“已拾橡果”，野莓采集累计不会因喂松鼠而减少。账本概览的数字在六位以内显示原值；达到七位后以“万”“亿”缩写，悬停可查看精确数字。展开后的完整账本与待运明细始终显示完整数值，存档也保留完整数值。展开状态和新增计数都会随自动存档及 JSON 完整存档保存。

“农场全景”旁的按钮或键盘 `P` 可切换全屏纯享模式，画面保留地图、退出按钮与保存全图入口；地图会随屏幕比例扩展视野、铺满左右两侧，仍可拖动和滚轮缩放。缩小到整张地图比窗口窄或矮时，空出的边缘才显示深色补边，地图保持居中。全屏时可用“提示：开/关”控制鼠标悬停提示，默认开启，选择会随农场存档保存。可按 `Esc` 退出；浏览器若不允许原生全屏，会使用铺满窗口的纯享视图。

侧边的“农场存档”可将**完整状态**导出为 ZIP 或 JSON 文件：当前日期与时刻、季节和天气、金币与建设、每格作物的生长、订单、采集点、视角、工具选择，以及工人、家畜和野生动物的当前位置与行动都会保存。导出默认勾选“ZIP 压缩”和“精简 JSON”，ZIP 内包含一个完整 JSON 存档。取消“ZIP 压缩”可直接下载 JSON；取消“精简 JSON”可保留缩进与换行。ZIP 和两种 JSON 排版均保留完全相同的状态字段。导入只需上传文件，程序自动识别 JSON 或 ZIP、解压并检查完整状态，不需要选择格式。ZIP 内应只有一个 JSON 文件；文件及解压后的 JSON 上限均为 2 MB，超限、缺少存档或有多份 JSON 的压缩包会被拒绝。导入只接受这种完整状态文件，并从对应的状态继续演变；文件先经过格式和数据检查，损坏的文件不会覆盖当前农场。浏览器本地自动存档也保留这些动态状态。

“保存完整农场图片”会把**当前时刻整张 2048 × 1920 地图**绘制为 PNG，包括当前视野之外的森林、湖泊、广场、山谷与村口。画面保留当下的作物形态、动物位置、季节、天气和昼夜光照；导出时不会移动正在查看的地图。全屏纯享模式右上角也有“保存全图”按钮。PNG 只用于欣赏或分享，继续游玩请使用 JSON 存档。

“加载 v1.0 默认农场”可以直接体验发布时的**第 1399 天完整农场**，恢复作物、居民与动物的行动、货运、天气和视角等全部状态。加载前会询问是否替换当前农场与浏览器自动存档；想保留自己的进度时，请先导出。取消或文件读取、校验失败不会覆盖当前进度。加载成功后刷新即可继续这份农场；页面不会自行加载默认存档。通过本地服务器或直接打开 `index.html` 均可使用。

## 收货计划与日记

侧栏在阿运状态下显示下一站和本趟收货顺序。去程与在主场过夜时提示「返程出发时规划」；返程出发后显示已经确定的货箱顺序，已收货地点带勾，下一站随实际路线更新。未安排的货箱不插入本趟路线；小地图不额外画货运路线。

农场日记保留最近 **10 条**消息，默认显示前 **4 条**，其余在日记内滚动查看。界面定时更新不会重建未变化的列表；阅读旧消息时，新消息出现会尽量保留当前阅读位置。日记随浏览器自动存档和完整 JSON 存档保存。
