## 2026-10-09 · Debug 性能卡片

### 规则与实现

- 右栏底部新增「Debug · 性能」，使用原生 `details`，默认收起，鼠标与键盘均可展开。
- 展开后每秒显示真实 FPS、帧间隔、整帧脚本平均值、窗口内最慢帧，以及模拟、地图绘制、界面/悬停/居民小像、自动存档的每帧平均耗时。脚本计时不含浏览器合成与 GPU，不将低频存档单次耗时冒充平均值。
- 暂停时模拟与自动保存为零，显示动画继续；收起后停止计时和数字刷新，再次展开与恢复可见时重置窗口。统计与开关不写存档、不影响世界速度。
- 独立文件 `js/ui/debug-performance.js` 和 `css/debug.css`；计时边界在原 `ui/app.js` 主循环，保持启动脚本与响应式样式最后加载。
- 默认选择：增加 FPS 与原始帧间隔，方便区分脚本执行和浏览器等待；统计频率每秒一次，避免调试面板频繁更新。

### 实际验证（已完成）

- 两个 JavaScript 文件语法检查通过。
- `node kits/farm/tests/debug-performance.cjs` 通过：实际 `tick()` 的确定性耗时、原始 100 毫秒帧间隔、低频 UI/自动存档平均、默认收起、收起停止、暂停与后台恢复。
- 实际浏览器隔离页面验证默认收起、展开数据刷新及暂停显示，控制台无错误。一次运行窗口约 60.0 FPS、16.68 ms 帧间隔、11.75 ms 整帧脚本；暂停窗口约 60.0 FPS、11.31 ms 整帧脚本，模拟和自动存档均为 0.00 ms。数字是此设备、此窗口的一次采样，不作为固定性能承诺。
- 已保存展开后的截图。验证页屏蔽读写玩家缓存，结束后删除临时页面、关闭测试标签和本轮本地服务；正式默认存档未改动。
