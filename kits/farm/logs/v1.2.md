# 苔谷农场 v1.2 · 从农场长成村庄

发布日期：2026-10-09。**状态：正式发布。**

[进入农场](../index.html) · [世界与玩法](../doc/世界与玩法.md) · [村庄发展](../doc/村庄发展.md) · [旅人与公共生活](../doc/城镇发展.md)

v1.2 包含 [v1.1 开发成果](v1.1.md) 和后续村庄建设、草地养护与修复。v1.1 未单独发布，因此从正式 v1.0 升级的玩家会同时获得这两轮变化。本页按最终玩法汇总，开发过程与实际验证分别保存在 [基于 v1.0 的历史](../doc/history/持续开发记录-v1.0.md) 和 [基于 v1.1 的历史](../doc/history/持续开发记录-v1.1.md)。

## 从自然草地开始

- 新农场保留主场、基础村口与六位居民，必要道路连接现有生活和工作区域。
- 偏远区域先是有草木和野生动物的自然地带，房屋、栈桥、围栏、矿轨及其支路随建设出现。
- 杂草以大小、疏密不同的草簇散落，小树有多种形态；未建支路也长草，不提前留下完整裸地或路头。
- 扩田、蜂巢、集市与苗床恢复仍由原村民自主推进，不占施工队列；主场南扩田后阿麦加入农务，苗圃保留 100、200、300 件送货门槛。

## 施工队与居民迁入

阿梁、阿砚一次建设一个地方。十二项工程达到积蓄和前置条件后排队，开工支付一次费用，保留经营储备；主要工程费合计 **47800 金**。

**修通道路与桥梁 → 清理实际占地 → 搭建设施 → 工程收尾 → 完工开放。**

- 工人从已有通路前端逐段铺路，建筑逐步出现地基、框架、墙体与屋顶。公共路段只建一次，未接通的桥不能通行。
- 有屋主的工程由屋主辅助建设，暂住施工队小屋；完工后带行李实际走到新家，再开始生产。公共工程没有搬家，阿牧扩建山羊牧场后回原来的家。
- 羊牧场先于山羊牧场，南方山谷先于矿区，旅人驿屋先于驴驿配套道路。具体门槛、价格、工期与名单见 [工程规则](../doc/村庄发展.md)。
- 点击等待工程可提前到满足依赖的最早位置：无依赖的 C 可把 A B C 调成 C A B，依赖 A 时调成 A C B。正在施工的工程不变，暂停时也可排序。
- 夜里返家，小雨降低效率，大雨雪停工；欢庆日停工赴会、散场直接回家。中断与读档保留施工进度，不重新收费。
- 阿运只收已开放货箱，以返程出发时的现货规划，抵达后取走全部货物；牧场未开放时，南部田地收成暂存主场货箱。

## 完工后继续照料村庄

全部主要工程与居民安顿完成后，施工队兼做草地养护。

- 每次清理 **30 簇 / 300 金**。可维护成熟草簇至少三十簇时，适宜工作日自动委托，仍保留经营储备；完成后自动休息至少五天。
- 玩家可在「村庄发展」卡片提前安排下一趟。两人分别认领草簇，实际抵达后割草，随后直接找下一处；夜晚、雨雪和欢庆保留同一份已付费任务。
- 原草簇保留位置和形态，全图每天约一至两簇新芽，约八个有效生长日长成，秋季减慢、冬季停长。割后至少十天才有机会再萌芽，额外新草数量有上限。
- 道路、房屋、田地、工作院落与通道持续保持清理；森林、湿地和矿坡自然植被保留。生长、随机选择、清理与委托进度完整保存。

## 旅人与真实的金币开销

以下为 v1.1 开发成果，一并进入本次版本：

- 旅行商人阿棠带来按财富阶段变化的商品、报价和故事，玩家可点击货车购买，公共预算也能自主添置与养护。
- 六类生活改善分阶段建造，花园、鸟食、花茶、茶点、牧草与暖炉木柴形成实际购买、运输和消费；收藏购得后才增加架子。
- 驿屋院落、茶桌、明信片、写生册、音乐盒、风铃、门灯与共用布伞带来日常活动。阿棠与邻居问候、喝茶，旅伴豆豆会跟随、玩耍与歇脚。
- **v1.2 调整开放条件：旅人驿屋建成且积蓄至少 5000 金后，阿棠才择日来访。** 商品仍按本趟来访时财富选择，小工程和采购等待对应基础设施开放。
- **广场建成后才有十日欢庆。** 未建时正常工作，不扣欢庆预算、不顺延订单、不提前停发两天货运；白天落成从下一次欢庆日开始。

## 更丰富的东岸与生态

沿用 v1.1 的最终成果，地图由 v1.0 的 **2048 × 1920** 向东扩为 **2560 × 1920**。

- 东岸新增驴驿、旅人花园、林泉、花坡、栎树休憩角与山脚小塘，矿坡东侧低山脊保留自然边界。
- 小驴有吃草、喝水、避雨、归棚和相伴行为；阿宁会带胡萝卜探访。山雉、花栗鼠与啄木鸟各有觅食、落脚与归窝过程。
- 猫咪玩球、作伴和喝水，麻雀拜访屋檐，松鼠吃野莓，狐狸散步归窝，乌龟晒背、苍鹭试探鱼群，鸳鸯相伴、水鸭问候阿蓼。
- 蝴蝶访花、雨后浴鸟与蛙鸣、暖季萤火虫、栎树落果、阿宁放纸船和阿运交货后买小饼，让生产之外也有日常故事。
- 村口喷泉有落水、水花与涟漪。暂停冻结世界进度，保留角色原地动作和天气、喷泉等显示动画。

## 看得见的居民与记录

- 「在村居民与旅人」独立成卡片，每人显示姓名与正面动态小人；悬停或聚焦查看实时活动，点击定位本人或住处，只列实际到村的人。
- 村庄发展显示当前施工、等待队列和未来条件，默认展开；发展与近况限制整体高度，超出内部滚动。右栏按控制、总览、生活、发展经营、记录和设置排列。
- 「旅人与小镇」在首次来访后出现；地图货车面板支持点击外部关闭，纯享模式也能购买。
- 日记保留当天全部消息，在四条高度内滚动；「复制当天」按发生顺序复制完整日期、时间与文本。
- 暂停、刷新、定位与导出图片都不会推进生产、建设、养护或随机选择。

## 画面与行走修复

- 道路恢复自然晕边，合并交叉口与施工分段，避免重复叠色和细缝；香草居与施工队小屋复用已有道路，不再铺平行双层路。
- 初始森林支路、广场入口与矿区连接随工程铺设；村口收矿摊屋随矿区搭建。村口转角、南谷茶亭入口、小地图和实际通行同步。
- 西湖等各处水底、河流与浅溪，以及草地、村口院落和矿坡底色，消除缩放时的网格接缝，保留岸线与季节变化。
- 村口东南路灯移入街间草地；驿屋茶桌南侧多余绕行路恢复草地，居民沿保留通路避开货车与路灯。阿宁花茶、茶点共用 15:36 返程截止。
- 修复湿地木板桥附近施工队卡住不夜归，失败空路线可重新规划，读档后继续实际返家。
- 草木按实际坐标和建成占地清理，补齐渔屋、香草居、货箱、茶桌、长椅、矿车位、苗床通道、猫屋、巢箱和驴圈，未开放花园与自然栖息地保留。
- 修复重新开始时旧动画时钟与工人残留行动；统一玩家文案，居民活动查询归入行为层，绘制与界面只读状态。
