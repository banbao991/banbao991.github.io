v1.3基于正式[v1.2](v1.2.md)开发，主要改善绘制成本和视角操作，保留全部玩法、对象、地图布局、交互、渲染顺序与暂停原地动画。村庄发展和草地养护继续按原规则运行。

## 绘制优化

完成14项已验证优化：基础草地栅格、水岸与村庄地面分组、道路路径、湿地精确湿度、原生地面路径、精确颜色、工程分类、植物占地、河湖底色、单帧自然地块筛选、矿坡地面、水鸭池以及移动镜头地表颜色复用。

| 同环境场景 | 原版 → 优化：平均CPU绘制 | P95：原版 → 优化 |
| --- | --- | --- |
| 晴天全图暂停，前13项累计 | 20.592 → 3.546 ms（减少82.8%） | 22.60 → 4.00 ms |
| 正常运行，前13项累计 | 20.340 → 3.936 ms（减少80.6%） | 22.20 → 4.30 ms |
| 拖动，第14项对比前13项 | 9.619 → 8.336 ms（减少13.3%） | 11.70 → 10.20 ms |
| 缩放，第14项对比前13项 | 9.545 → 8.212 ms（减少14.0%） | 11.60 → 10.20 ms |

基准为第742天默认存档、普通视图全图，内部Canvas1152×816、缩放0.425；夜晚、雨雪另测。数据来自2026-10-10相同状态、镜头和动画时钟的前后配对测量，不是本次整理时的新测速。第14项不改变固定全图的主要耗时。不同轮次收益不能相加，数据不含模拟、浏览器合成与GPU完成时间，设备表现可能不同。P95表示95%的样本耗时不超过该值；以平均耗时与P95评估，FPS仅辅助。

缓存只保存派生绘制数据，不进入农场或存档。连续季节颜色、湿度与动画不降精度；镜头、尺寸、工程通路和实际颜色变化时按对应规则更新。完整地图PNG导出保留独立画布处理，旧环境保留直接绘制回退。未达到明显收益门槛的实验没有接入，性能续作定时任务已停止。

## 性能面板与地图视角

- 右栏底部「Debug · 性能」默认收起。展开后每秒显示真实FPS、帧间隔、整帧脚本平均值、最慢帧，以及模拟、地图、界面和自动存档的耗时。
- 收起后停止统计，暂停时仍可观察绘制和原地动画；调试开关不保存到玩家进度。
- 普通视图与全屏纯享共用全图缩小下限。按钮、滑杆、滚轮与键盘可缩小到完整地图；到达下限时禁用继续缩小，退出纯享不强制放大到70%。具体百分比随内部画布尺寸变化。

## 存档与默认农场

浏览器缓存键、JSON/ZIP存档格式与运行状态语义沿用v1.2。正常打开恢复自己的进度，不主动加载默认农场，也不重置金币、设施、队列、居民、动物或动画状态。

本版继续使用[v1.2第742天完整默认农场](../saves/v1.2/苔谷农场-第742天.zip)及同目录本地读取副本，侧栏仍明确标注「加载 v1.2 默认农场」。发布版本与示例存档来源分别标注；本轮没有重新生成或改写默认存档，原v1.0存档也保留。

- 本版开发过程归档在基于v1.2的历史文件；后续开发使用[基于v1.3的记录](../doc/history/持续开发记录-v1.3.md)，旧版本历史保留。
