## 首个正式版本

这一版本记录目前完成的苔谷小世界：

- **连续演变的世界**：昼夜、四季、天气渐变，夜间加速、冬季降雪，以及分阶段生长的作物和建设。
- **完整地图与自由视角**：主场、森林、村口、广场、西湖、湿地苗圃、香草田、牧场、山谷和矿坡；拖动、缩放、小地图、全屏纯享与提示开关。
- **自主生活与货物流通**：居民种植、采收、挤奶、养殖、垂钓、巡林、育苗和采矿；阿运按返程出发时的货箱状态安排路线，阿矿定期送矿。
- **公共生活与生态**：每十天欢庆、按农场金币筹备活动，居民停工赴会再返家；广场橘白猫、奶牛猫和麻雀，以及森林、河湖、湿地中的动物互动。
- **可靠的进度与记录**：浏览器自动保存完整状态，ZIP/JSON 导入导出、完整地图 PNG、分类账本、多订单和农场日记。
- **统一的场景层级**：人物脚底、建筑底边、树根与前后围栏参与深度排序；彩带、停栖鸟和灯光跟随各自承载物。

## 默认农场

发布存档：[苔谷农场 · 第 1399 天](../saves/v1.0/苔谷农场-第1399天.zip)。原始 ZIP 保存在 `saves/v1.0/`，随站点一起分发。

侧栏“农场存档”中新增 **加载 v1.0 默认农场**。玩家确认后恢复整份存档并保存到浏览器，刷新可继续；取消或读取、校验失败时保留当前进度。自己的农场可先导出备份。正常启动仍恢复原来的浏览器缓存，默认存档只在玩家主动选择时加载。

HTTP 页面直接读取 ZIP；直接打开本地页面时使用同一 ZIP 的编码副本。更新发布存档后运行：

```powershell
node kits/farm/scripts/bundle-default-save.cjs 1.0
```

**游戏发布版本 v1.0 与存档格式编号分别管理**，本次没有改变完整状态存档格式。
