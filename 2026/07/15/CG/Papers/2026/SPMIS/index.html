(论文)[2026-EG] Stochastic Pairwise MIS for Unbiased Large-Kernel Reuse in Real-Time

Posted on 2026-07-15 Edited on 2026-07-25 In CG.Paper Views:
本文提出了随机 MIS 的算法，在 MIS 系数中引入随机性，不需要完整计算周围 M 个样本的权重，而是随机采样 N 个样本的方式计算，能够进行更大的空间复用

Stochastic Pairwise MIS for ReSTIR PT

  • 主页，代码（给了 DI 的原型实现）
  • 本文提出了随机 MIS 的算法，通过在周围 \(M\) 个样本中随机采样 \(N\) 个样本的方式进行空间复用
    • 在 MIS 系数中引入随机性，这样能够计算更大的 \(M\)，复杂度为 \(O(MN)\)
    • 随机 PMIS 进一步降低了算法复杂度，\(O(N)\)
  • 提升 spatial reuse 效率
  • 实现上，通过 hash 的方式将像素划分为 cell
    • 先采样 cell【找到一个邻域】，hash 的方式能够扩大邻域
    • 然后在 cell 中采样 \(N\) 个像素【本文的随机性】
    • 计算贡献
  • 额外开销
    • 初始的 cell 选取【12 轮根据 confidence sum 的重采样】
    • \(\tilde{N}_c+\tilde{N}\) 次 shift mapping
    • 不需要原来的空间复用开销（\(M\)）
  • 一个 cell 中的相似性和 Hash 没关系【Hash 理解为离散等价类划分】
    • 连续属性的相似性 => 量化离散标签相同 => Hash 到同一个 Cell
    • 离散属性分桶后用 Hash 实现高效索引
  • Hash 碰撞，向后走；kLinearProbeLength=32

引言

  • 当样本稀疏分布的时候，之前的空间复用低效
  • 论文能够实现更大范围的无偏复用，进一步提升 PMIS（Pairwise MIS）的效率【需要评估所有复用的 MIS 时】
    • 基于 GRIS

背景知识

  • 细节查看 ReSTIR Notes
  • 基本 RIS 权重：都覆盖定义域

\[ w_i=\frac{\hat{p}(X_i)}{p_i(X_i)} \]

  • Canonical samples【基准样本】
    • 在 target domain 上
    • shift mapping 是恒等变换 \(T_c(X_c)=X_c\)【覆盖整个定义域】
    • 每次复用需要有一个基准样本，保证无偏
      • 可以理解为当前像素的样本【reservoir 蓄水池】
  • GRIS
  • generalized balance heuristic：BH 基础上 \(p\) 乘上 \(c_i\)（confidence weight）
    • generalized 指的是使用 \(\hat{p}\) 代替 \(p\)【UCW】
    • 这里的 \(\leftarrow\) 下标指的是变换到 target 域下的函数值

\[ m_i^{\mathrm{bal}}(y) = \frac{ c_i\,\hat{p}_{\leftarrow i}(y) }{ \displaystyle \sum_{j=1}^{M} c_j\,\hat{p}_{\leftarrow j}(y) } \]

  • confidence weights
    • 一般设置为生成这个样本的总初始样本数目
      • 可能重复计算导致过大；不同像素空间不一样这个近似不准
    • 加入 confidence cap【GRIS 设置为 20】
  • 本文输入：\((X_i,W_{X_i},c_i)\)
  • Pairwise MIS
    • 降低 MIS 计算量：\(O(M^2)\to O(M)\)
    • defensive 形式：避免给 canonical 样本过大权重，同时不能让其他样本的 \(\hat{p}\) 过大
      • canonical 样本权重除以 \((M-1)\)，整体在加 1；然后所有平均
    • confidence weight 版本：不使用 \(M-1\) 而是用 \(c_i\) 调制【\(c_i=1\) 退化为上面的】

\[ m_i^{\mathrm{pw}}(y) = \left( \frac{c_{\Sigma}} {c_{\Sigma}+c_c} \right) \frac{ c_i\hat{p}_{\leftarrow i}(y) }{ c_{\Sigma}\hat{p}_{\leftarrow i}(y)+c_c\hat{p}(y) } \qquad (i\ne c) \tag{11(a)} \]

\[ m_c^{\mathrm{pw}}(y) = \frac{c_c}{c_{\Sigma}+c_c} + \sum_{j=1}^{M} \left( \frac{c_j}{c_{\Sigma}+c_c} \right) \frac{ c_c\hat{p}(y) }{ c_{\Sigma}\hat{p}_{\leftarrow j}(y)+c_c\hat{p}(y) } \tag{11(b)} \]

\[ c_{\Sigma}=\sum_{k\ne c}^{M} c_k \]

  • ReSTIR
    • 初始样本（initial candidates）来自于 PT，多个的话，合并到 initial samlple 中【RIS】
    • 时间复用：和上一帧对应像素样本合并【GRIS】
    • 空间复用：和周围像素样本合并【GRIS】

GRIS 理解

  • 输入为 M 样本的 UCW 对 \((X_i,W_{X_i})\)
    • 可能不是当前像素的 UCW，但是经过 shift mapping 之后有类似形式的当前像素中的 UCW
    • 理解为新 UCW 对
      • \(Y_i=T_i(X_i)\)
      • \(W_{X_i}\left|\dfrac{\partial T_i}{\partial X_i}\right|\)
        • pdf 的话是除以 Jacobian，因此 UCW 就是乘【pdf 和 UCW 为倒数关系】
    • 对于当前像素的定义域的任意函数 \(g\)【无偏性分析中，采样和积分函数 \(g\) 无关】

\[ \mathbb{E}\left[ g\left(T_i(X_i)\right) W_{X_i} \left| \frac{\partial T_i}{\partial X_i} \right| \right] = \int_{\Omega_i} g\left(T_i(x)\right) \left| \frac{\partial T_i}{\partial x} \right| \,\mathrm{d}x = \int_{T_i(\Omega_i)}g(y)\,\mathrm{d}y \]

  • GRIS 重采样权重
    • RIS 基础上的变换
      • \([\cdot]\) 表示示性函数：表示 \(T_i\) 是否有定义
      • shift mapping
      • \(p(X_i)\) 使用 UCW
      • MIS 系数

\[ w_i = \left[X_i \in D(T_i)\right] m_i(Y_i)\, \hat{p}(Y_i)\, W_{X_i}\, \left| \frac{\partial T_i}{\partial X_i} \right| \tag{6} \]

  • 最终采样 index 权重

\[ P(z)=\frac{w_z}{\sum_{j=1}^{M}w_j} \]

  • 最终样本 \(Y_z\) 的 UCW

\[ W_Y=\frac{1}{\hat{p}(Y)}\sum_{j=1}^{M}w_j \]

Stochastic Resampling MIS Weights

  • 如果 M 个蓄水池中大部分样本都是零贡献的，GRIS 变得低效
  • 不能直接根据样本挑选，有偏！
  • 论文：更大的 \(M\) 中挑选 \(\tilde{N}\) 个样本用于复用【设计 MIS、无偏复用】
  • 构建 MIS 系数的随机估计
    • 输入样本 \(\bar{X}=(X_1,\cdots,X_M)\)
    • UCW \(\bar{W}=(W_{X_1},\cdots,W_{X_M})\)
    • 新随机变量 \(Z\)

\[ \mathbb{E} \left[ \tilde{m}_i(Y_i;Z) \mid \bar{X},\bar{W} \right] = m_i(Y_i) \tag{13} \]

  • 重采样权重 \(\tilde{w}_i\)【带入 \(\tilde{m}_i\) 即可】

General Stochastic Resampling MIS Estimator

  • \(M\) 个样本，每个样本有一个采样概率 \(P(i)\)
  • 有放回采样 \(\tilde{N}\) 次，得到集合 \(\bar{S}=\{S_1,\cdots,S_{\vert S\vert}\}\)
    • \(\vert{S}\vert\le\tilde{N}\)：因为有去重
    • \(\mathbf{K}_{\bar{S}}(i)\)：记录像素 \(i\) 出现的次数
  • 此时随机重采样 MIS 为
    • \(m_i\) 表示原来的非随机 MIS【例如 BH 或者上面的 confidence weight】
    • 允许 \(P\) 依赖于输入样本和 UCW
    • \(P(i)=0\) 的时候，\(\mathbf{K},\tilde{m}\) 都设置为 0
    • 【满足期望为 \(m_i\) 证明见附录】

\[ \tilde{m}_i(Y_i; Z) = \frac{\mathbf{K}_{\bar{S}}(i)} {\tilde{N}{P}(i)} m_i(Y_i) \tag{15} \]

Stochastic Pairwise MIS

  • 不使用 Pairwise 的话，复杂度为 \(O(\tilde{N}M)\)
  • 用上：\(O(\tilde{N})\)
    • 当 \(\tilde{N}\ll M\) 时高效

non-canonical

  • 对于 \(i\ne c\)，式子 11(a) 的随机版本如下【怎么算 \(c_{\Sigma}\)？预计算好，后面 cell 划分有讲】

\[ \tilde{m}_i^{\mathrm{pw}}(Y_i) = \frac{\mathbf{K}_{\bar{S}}(i)} {\tilde{N}{P}(i)} \left( \frac{c_{\Sigma}} {c_{\Sigma}+c_c} \right) \frac{ c_i\hat{p}_{\leftarrow i}(Y_i) }{ c_{\Sigma}\hat{p}_{\leftarrow i}(Y_i)+c_c\hat{p}(Y_i) } \qquad (i\ne c) \tag{16} \]

  • 理论上，\(P(i)\) 正比于 \(w_i\)（式子 6）时最优
    • 但是需要 shift mapping 计算，这个很耗时
    • 启发式的使用如下式子
      • 被 confidence 加权的 luminance，直接可以获得，设置 \(\hat{p}\) 为 \(f\) 的 luminance【怎么算 \(\hat{p}\)？就是蓄水池保存的贡献结果】
      • shift mapping 高效的时候，结果好【高效：\(\hat{p}(X_i)\) 和 \(\hat{p}(Y_i)\) 高度相关】

\[ P(i)\propto c_i\hat{p}(X_i)W_{X_i} \]

  • 好处是，和 GRIS 相比，大的 \(M\) 总能找到有效样本

canonical

  • \(i=c\)
  • 采样一个不同的 \(\tilde{N}_c\) 像素，采样概率 \(P_c(i)\)
  • 有放回采样 \(\tilde{N}_c\) 次，得到集合 \(\bar{S}'=\{S_1',\cdots,S_{\vert S'\vert}'\}\)，计次 \(\mathbf{K}_{\bar{S}'}(i)\)
  • 式子 11(b) 的随机版本

\[ \tilde{m}_{c}^{\mathrm{pw}}(Y_c) = \frac{c_c}{c_{\Sigma}+c_c} + \sum_{i\in\mathcal{S}'} \frac{ \mathbf{K}_{\bar{S}'}^{(i)} }{ \tilde{N}_cP_c(i) } \beta_i(Y_c) \tag{18} \]

\[ \beta_i(Y_c) = \left( \frac{c_i}{c_{\Sigma}+c_c} \right) \frac{ c_c\hat{p}(Y_c) }{ c_{\Sigma}\hat{p}_{\leftarrow i}(Y_c)+c_c\hat{p}(Y_c) } \tag{19} \]

  • 无偏：\(c_i>0 \Rightarrow P_c(i)>0\)
  • 直观：\(P_c(i)\propto c_i\)
    • 实际上设置为 \(1/M\) 效果就不错
  • 为什么要用两个估计？我猜是因为二者估计的量差的很大，用两个质量更高，从不同的 pdf 也可以看出

Non-Canonical Confidence Adjustment

  • \(M\) 比较大的话，\(c_{\Sigma}\) 很大，此时选中样本权重很小，导致暗噪点
    • 典型场景：周围像素邻居的 shift mapping 失效，自身像素的质量很高；此时自身像素样本权重反而很低
  • 方案：对 \(c_{\Sigma}\) 使用 \(\tilde{N}/M\) 进行 scale

实现

  • 算法支持很大的 \(M\)
  • 但是随着距离变大，相似性变差
  • 把像素划分为 cell，然后在 cell 内部进行复用
  • tile：8x8 像素块【只是一种物理划分，除了计算 hash，似乎没啥用了】
  • 每个像素 hash
    • tile ID【8x8】、object ID、量化的 surface normal
    • PCG【总体上相当于 pcg(a + pcg(b)) 这种形式】

找相关 cell

  • 简单相邻复用效果不好
    • 相关性
    • 无法处理 large occlusion【都落在里面】
  • WRS 多轮采样 cell【12 轮迭代，每轮迭代半径 x1.25，初始 30px】
    • 当前半径内，随机采样一个像素；找到对应 cell
    • 通过 Normall 和 Object ID 判断是否相似
      • 相似则作为候选样本【WRS】，权重设置为 cell 内所有像素的 confidence sum
      • 否则直接丢弃

GPU 实现

Cell 构建

  • 使用两个 multimap 实现
    • cellPixelIndices【gReservoirCellInverseMap】：保存这个 cell 里面的所有像素
    • cellReservoirs【gReservoirCellMap】：保存这个 cell 里面的非零贡献的像素【UCW > 0】
  • multimap 实现：3 个 pass【结果上来说就是让 cell 中左右内部像素在 memory 中相邻】
  • pass 1：将所有像素插入 multimap 中，对于每个像素
    • 计算 hashed cell ID
    • 插入到对应的 multimap 中，同时更新当前 cell 的 confidence sum【原子加法】
    • 【根据结构体中的含义更新即可】
  • pass 2：更新 cellOffsets【前缀和，当前 cell 前面有多少个像素，cell 中第一个元素在整个数组中的 offset】
    • 两个 multimap 都更新
    • GPU 并行前缀和【因为 cell 顺序没有用】；原子加法
      • 前缀和，但是数组元素谁在前面无所谓
  • pass 3：排序
    • 根据 dataIndices 从 data 中读取原始信息，然后根据 cellOffsets 和 dataIndices[1] 把具体信息填入 sortedData

空间采样

  • 下面所有的 \(c_{\Sigma}\) 都已经是被 \(\tilde{N}/M\) scale 了的
  • \(Y\leftarrow \emptyset\)
  • 采样一个 cell，上面找 cell
    • 这里需要用到每个像素对应蓄水池的 confidence weight【还是无偏的吗？】以及 normal 信息【样本无关】
    • 此时 cell 里面有 \(M\) 个样本
  • 先根据式子 (18) 计算 canonical 权重
    • cell 中均匀采样 \(\tilde{N}_c\) 次【\(p=1/M\)】
    • \(\mathbf{K}\) 计数，本质上就是每次采样得到一个样本，就把贡献加上去
    • ReservoirMerge 就是 WRS

  • 式子 (16) 计算 non-canonical 权重

  • 上面一共需要 \(\tilde{N}_c+\tilde{N}\) 次 shift mapping

GRIS with Stochastic MIS

  • 使用随机 \(\tilde{w}_i\) 替换

\[ \mathbb{E}\left[f(Y)W_Y\right] = \sum_{i=1}^{M} \mathbb{E} \left[ [\tilde{w}_i>0] f(Y_i)W_{Y_i} \frac{\tilde{w}_i}{\sum_{j=1}^{M}\tilde{w}_j} \right] \]

  • 代入 UCW 的估计

\[ = \sum_{i=1}^{M} \mathbb{E} \left[ [\tilde{w}_i>0] f(Y_i) \left( \frac{1}{\hat{p}(Y_i)} \sum_{j=1}^{M}\tilde{w}_j \right) \frac{\tilde{w}_i}{\sum_{j=1}^{M}\tilde{w}_j} \right] \]

  • 约掉分母

\[ = \sum_{i=1}^{M} \mathbb{E} \left[ [\tilde{w}_i>0] f(Y_i) \frac{\tilde{w}_i}{\hat{p}(Y_i)} \right] \]

  • 带入 Jacobian
    • \([D_i]\) 示性函数

\[ = \sum_{i=1}^{M} \mathbb{E} \left[ [D_i] f(Y_i) \frac{ \tilde{m}_i(Y_i;Z)\hat{p}(Y_i)W_{X_i} \left|\frac{\partial T_i}{\partial X_i}\right| }{ \hat{p}(Y_i) } \right] \]

\[ = \sum_{i=1}^{M} \mathbb{E} \left[ \mathbb{E} \left[ [D_i] f(Y_i) \tilde{m}_i(Y_i;Z) W_{X_i} \left|\frac{\partial T_i}{\partial X_i}\right| \right] \middle| \bar{X},\bar{W} \right] \]

  • 后续证明思路就是，找个地方把 \(\tilde{w}_i\) 给求期望，换成 \(w_i\)；然后就是原来的 ReSTIR 推导了

\[ = \sum_{i=1}^{M} \mathbb{E} \left[ [D_i] f(Y_i) \mathbb{E} \left[ \tilde{m}_i(Y_i;Z) \middle| \bar{X},\bar{W} \right] W_{X_i} \left|\frac{\partial T_i}{\partial X_i}\right| \right] \]

证明 SMIS 期望

  • 满足 \(\mathbb{E}[\tilde{w}]=w\)
  • 对 \(Z\) 求期望，也就是 \(\mathbf{K}\)

\[ \mathbb{E} \left[ \tilde{m}_i(y;Z) \middle| \bar{X},\bar{W} \right] = \mathbb{E} \left[ [P(i;\bar{X},\bar{W})>0] \frac{ \mathbf{K}_{\bar{S}}{(i)} }{ \tilde{N}P(i;\bar{X},\bar{W}) } m_i(y) \middle| \bar{X},\bar{W} \right] \]

  • 考虑 \(m_i>0\)【=0 显然】
  • 给定 \(\bar{X},\bar{W}\)，\(P\) 是常数，直接提出来

\[ = \mathbb{E} \left[ \frac{ \mathbf{K}_{\bar{S}}{(i)} }{ \tilde{N}P(i;\bar{X},\bar{W}) } m_i(y) \middle| \bar{X},\bar{W} \right] \]

\[ = \mathbb{E} \left[ \mathbf{K}_{\bar{S}}{(i)} \middle| \bar{X},\bar{W} \right] \frac{1}{ \tilde{N}P(i;\bar{X},\bar{W}) } m_i(y) \]

  • 有放回采样，伯努利分布
    • 期望为 \(Np\)
    • 消掉分母
