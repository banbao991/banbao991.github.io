(论文)[2025-SIGC] Neural Importance Sampling of Many Lights

Posted on 2025-10-22 Edited on 2025-10-23 In CG.Paper Views:
直接光的多光源采样问题；使用神经网络预测每一个点的采样光源的分布（一个数组）；对于光源数量多的，首先使用传统方法建立一个全局共享的 light hierarchy，将其划分为若干子树；NN 估计对于不同子树的采样概率（子树内的采样和传统方法相同）

Neural Importance Sampling of Many Lights

  • PEDRO FIGUEIREDO, Texas A&M University, USA
  • 项目主页，代码实现
  • 直接光的多光源采样问题
    • 和 PG 的区别：小而强的占据小立体角的光源，PG 方法很难学习
  • 使用神经网络预测每一个点的采样光源的分布（一个数组）【光源内部采样还是传统的】
    • 对于光源数量多的，首先使用传统方法建立一个全局共享的 light hierarchy，将其划分为若干子树；NN 估计对于不同子树的采样概率（子树内的采样和传统方法相同）

Neural Light Selection Importance Sampling

  • 考虑 DI
    • 一共 \(M\) 个光源，根据光源拆分

\[ L_o(\mathbf{x}, \omega_o) = \sum_{y=1}^{M} L_y(\mathbf{x}, \omega_o) = \sum_{y=1}^{M} \int_{A_y} F(\mathbf{x}, \mathbf{z}, \omega_o) \, dA_y(\mathbf{z}) \]

\[ F(\mathbf{x}, \mathbf{z}, \omega_{o}) = L_i(\mathbf{x}, \mathbf{z}) \, f_s(\mathbf{x}, \omega_{o}, \mathbf{z}) \, G(\mathbf{x}, \mathbf{z}) \]

  • 采样第 \(y\) 个光源概率：\(Y_j\sim p(y)\)
    • \(Y_j=\{1,\dots,M\}\)
  • 于是 MC 估计

\[ \langle{L_o(\mathbf{x}, \omega_o) }\rangle=\frac{1}{N}\sum_{j=1}^{N}\frac{L_{Y_j}(\mathbf{x}, \omega_o)}{p(Y_j)} \]

  • 估计 \(L_{y}(\mathbf{x}, \omega_o)\) 需要在光源 \(y\) 上做 MC 积分
    • 这个就使用 PBRT 自带的了；论文只管选择光源
  • 论文：使用神经网络估计 \(p_{\theta}(y)\)
    • 表示形式就是一个数组

优化

  • KL 散度

\[ D_{\text{KL}}(q, p_\theta) = \sum_{y=1}^{M} q(y) \log \frac{q(y)}{p_\theta(y)} \]

  • 梯度

\[ \nabla_\theta D_{\text{KL}}(q, p_\theta) = -\sum_{y=1}^{M} q(y) \nabla_\theta \log p_\theta(y) \]

  • 使用 \(Y\sim p_{\theta}(y)\) 进行 MC 估计

\[ \langle \nabla_\theta D_{\text{KL}}(q, p_\theta) \rangle = -\frac{1}{N} \sum_{j=1}^{N} \left[ \frac{q(Y_j)}{p_\theta(Y_j)} \nabla_\theta \log p_\theta(Y_j) \right] \]

  • 定义目标分布：光源 \(y\) 的贡献除以所有光源总的贡献

\[ q(y|\mathbf{x}, \omega_o) = L_y(\mathbf{x}, \omega_o)\Big/ L_o(\mathbf{x}, \omega_o)=A\Big/ B \]

  • \(A\) 项使用 MC 估计【采样光源上的一个点，计算贡献】
  • \(B\) 项忽略【大家都是这么做的，例如 NPM】
    • Adam 优化器优化参数是根据当前梯度和历史平均梯度【被约分了】
  • 于是把采样光源上的点 \(\mathbf{Z}_j\) 也写进去，式子是这样的

\[ \langle \nabla_\theta D_{\text{KL}}(q, p_\theta) \rangle = -\frac{1}{N} \sum_{j=1}^{N} \left[ \frac{F(\mathbf{x}, \mathbf{Z}_j, \omega_o)}{p(\mathbf{Z}_j | Y_j) p_\theta(Y_j)} \nabla_\theta \log p_\theta(Y_j) \right] \]

网络架构

  • 3 hidden layers of 64 neurons
  • 输入
    • position：dense grid
    • outgoing direction：spherical harmonics with degree 4
    • normal：one-blob with 32 bins

Neural Light Cluster Sampling

  • 光源数目多了之后，直接输出数组不现实
  • 使用传统方法将光源划分为 clusters
    • 这个 cluster 是全局共享的【也就是说 \(p(y\mid c)\) 是全局一样的】
  • 于是采样过程转变为先采样 cluster，然后从 cluster 里面采样光源

\[ p_\theta(y)=p_{\theta}(c)p(y\mid c) \]

  • 网络只估计 \(p_{\theta}(c)\)

  • 另外的好处：可以使用传统数据结构的优势【后面说的残差学习】

cluster 构建

  • 使用传统方法构建 light hierarchy【论文使用 ATS 方法】
    • ATS：Importance Sampling of ManyLights with Adaptive Tree Splitting【2018-CGIT】
    • TODO：还没看
  • 固定全局的 \(k\)，让深度 \(\ge k\) 的成为 clusters

优化

  • 就是把 \(p\) 拆开

\[ \langle \nabla_\theta D_{\text{KL}}(q, p_\theta) \rangle = -\frac{1}{N} \sum_{j=1}^{N} \left[ \frac{F(\mathbf{x}, \mathbf{Z}_j, \omega_o)}{p(\mathbf{Z}_j | Y_j) p(Y_j | C_j) p_\theta(C_j)} \nabla_\theta \log p_\theta(C_j) \right] \]

残差学习

  • 问题：差的初始化让一开始训练慢
  • 使用传统方法作为基础，NN 估计和传统方法的残差
  • 如何保证最后的权重是正数？转化为指数上的残差
    • 神经网络估计：\(f_\theta(\mathbf{x}, \omega_o)[c]\)

\[ p_\theta(c) = \exp{\left(\log(w_c) + f_\theta(\mathbf{x}, \omega_o)[c] \right)}\Big/{\sum_{s=1}^{S} \exp{\left(\log(w_s) + f_\theta(\mathbf{x}, \omega_o)[c] \right)}} \]

  • 分母归一化保证是个分布；残差在指数部分保证是个正数
  • 这样 0 初始化让初始分布是传统方法的结果，初始好的结果让训练过程更稳定

结果

  • 实现：ATS 构建 light hierarchy；\(k=6\)【网络输出 64 个权重】
  • PBRT v4 + GPU 实现
  • 对比算法：ATS、SLCRT、ReSTIR、VARL
    • ReSTIR：\(M=32,K=3,R=30\) spatial reuse
  • 对比：第一个非 specular 面的 DI
  • 光源数量：几千个面
    • 例如 bedroom 场景就是镜子上面那两个灯；一共 4.7k 个面

实验

消融实验

  • 残差学习
    • 使用不同的传统方法构建初始 light hierarchy；或者不用
  • 位置输入编码
  • 训练时间占比【15% 最佳】
  • 连续表示：对比 pos 用 32x32x32 网格中心；dir 用 8 bins
  • 不同的 cluster level（\(k=6\) 大部分最优）

总结

  • future work
    • 保守优化减少 outliers
    • 目前使用一个全局的 cut；可以动态变化
    • 没有考虑光源内部的采样
